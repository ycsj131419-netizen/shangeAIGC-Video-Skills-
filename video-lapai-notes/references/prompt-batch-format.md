# 拉片提示词批次格式

当用户说“拉片提示词”“复刻提示词”“按批次输出提示词”“每13到15秒为一个批次”时，使用本格式。最终输出必须是可直接复制到视频生成工具的提示词，不要只给分析。

## 固定结构

每个批次都写成一个完整代码块：

```text
风格与场景段落。写清年代感、画面质感、场景、灯光、情绪、配音/音效风格。

场景：...

主角：

角色A：使用 [参考图文件名] 角色，外观、状态、情绪、动作任务、音色/配音（如果用户提供）。

角色B：...

全局空间锚点：

写清角色位置、左右/中间关系、面对方向、前景/背景关系、谁抢戏/不抢戏、哪些角色不能提前出现。必要时使用“从某角色视角看过去：左侧是..., 中间是..., 右侧是...”。

【分镜故事】

1 景别/角度	镜头运动	画面内容	音效/台词	时间
2 景别/角度	镜头运动	画面内容	音效/台词	时间
```

可在批次后补充：

```text
负面提示词：
...
```

## 写作规则

- 默认每批 13-15 秒；用户要求更快时可缩短到 7-10 秒。
- 每个批次都必须包含空间锚点。不要只在第一批写。
- 原视频已有对白必须尽量还原，不要自己改；新增剧情才按用户要求加台词。
- 用户给出角色替换图时，必须在 `主角：` 中绑定每个角色的参考图和状态。
- 位置关系不清时必须主动写清：谁在左、谁在中间、谁在右、谁面对谁。
- 不要使用表格。用户指定的 TSV 式分镜行可以保留在代码块内。
- 不要输出“可以这样”“建议这样”作为最终主体；直接给成品提示词。
- 不要把不相关旧剧情带进新提示词。

```text
90年代港片美学风格，老电影粗颗粒胶片质感，轻微放映划痕，帧闪烁效果，局部柔光处理。室内为同一间复古港式病房，暖黄色旧墙面，铁架病床、浅色床单、浅色棉被、旧式窗帘、搪瓷床头柜、输液架、心率监护仪，柔暖室内光，画面带轻微偏黄旧胶片色调。人物表演克制但情绪强烈，台词配音带老电影公放回声，搭配港式拟音音效。

场景：病房内。

主角：

...

全局空间锚点：

...

【分镜故事】

1 ...	...	...	...	0:00-0:03
2 ...	...	...	...	0:03-0:06
```

## 空间锚点示例

```text
富贵坐在主病床上，猫护士站在富贵病床旁边，正在拆富贵头上的纱布。富贵的视线方向正对床尾。床尾方向有三人组，从富贵视角看过去，位置必须固定为：左侧是坐轮椅的大哥，中间是站立的铁锤，右侧是站立的女主人。富贵的位置与床尾三人组形成正反打关系：先拍富贵病床方向，再反打到富贵看到的床尾方向。
```
