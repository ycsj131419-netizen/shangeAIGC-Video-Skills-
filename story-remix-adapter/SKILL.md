# Story Remix Adapter

## Purpose

Create a new, ownable story from a reference work by extracting the attraction mechanism, then rebuilding world, characters, conflicts, rules, scenes, dialogue, and ending direction. Do not merely polish, summarize, translate, or rename the source.

Read `references/adaptation-legal-and-craft.md` when doing a full adaptation, when the user mentions infringement/copyright, or when the source is a known/commercial work.

## Non-Negotiable Gate

Do not deliver an adapted script until it passes self-review and self-correction.

Automatic fail:

- The user asked for an overall/full adaptation, but the output only provides a strategy, outline, or a few sample episodes.
- A long source script is adapted into only 3-5 sample episodes without the user's explicit request for a sample only.
- The output is a close paraphrase of the source.
- The output keeps the same scene order, signature set pieces, named props, unique rules, punchline, or ending mechanism.
- Only names, era, location, professions, or genre surface have changed.
- The adapted work could substitute for the source in the same market.
- The work uses protected character expression, distinctive dialogue, exact plot expression, or iconic scene design from the source.
- The story logic is weaker than the source or no longer explains why viewers should keep watching.

If any automatic-fail issue appears, score below 90, revise, rerun checks, and only deliver after the score is 90+.

## Five-Step Workflow

### 1. Source Diagnosis

Identify:

- Genre, format, episode count, and target platform.
- Main hook: the precise reason viewers continue watching.
- Emotional engine: humiliation, rescue, revenge, wish fulfillment, taboo love, survival, justice, found family, etc.
- Structural engine: secret rule, debt reversal, hidden identity, resource discovery, trial, competition, deal, chase, inheritance, investigation, etc.
- Signature protected expression: names, exact relationship setup, scene order, special props, original rules, dialogue, iconic visuals, unique twists.

Output internally or briefly in final: `source hook`, `must-not-copy elements`, and `adaptable abstract mechanisms`.

### 2. Attraction Extraction

Extract only uncopyrightable or high-level mechanisms:

- Audience desire: what fantasy or fear does the story satisfy?
- Pressure pattern: what forces the protagonist to act now?
- Escalation rhythm: how does the problem worsen?
- Payoff type: what kind of emotional release makes it satisfying?
- Character contrast: what values collide?

Do not preserve the exact expression of these mechanisms. Use them as design constraints for a new story.

### 3. Worldview And Identity Replacement

Replace at least four of the following, and preferably all:

- Era and social environment.
- Industry/domain.
- Core resource or MacGuffin.
- Protagonist identity, weakness, and active skill.
- Antagonist power base.
- Family/romance/social relationship web.
- Supernatural/system/business rule.
- Key locations and visual symbols.
- Ending arena and public reckoning form.

The replacement must change causality, not only vocabulary. A changed world must create different choices, scenes, obstacles, and payoffs.

### 4. Rebuild Plot From Causality

Build a new outline before writing script pages:

- New premise in one sentence.
- Protagonist want, wound, skill, and first active choice.
- Antagonist want and pressure method.
- Rules planted before use.
- Three to five escalation turns.
- Midpoint discovery or irreversible choice.
- Climax that pays off the new world, not the source scene.
- Ending emotional value.

Only after this outline passes logic review, write the full script.

### 5. Consistency And Originality Check

Before final delivery, run:

- Story logic audit.
- Speaker/character motivation audit.
- Setup/payoff audit.
- World-rule consistency audit.
- Originality distance audit.
- Copyright-risk audit.
- Shootability audit.

Report the final score. If below 90, revise before showing the user.

## Output Formats

For full script adaptation:

1. `改编策略说明`
2. `原作吸引力机制`
3. `避险替换表`
4. `原创世界观与人物小传`
5. `原创故事梗概`
6. `分集大纲`
7. `剧本正文`
8. `自查自纠报告与评分`

Full adaptation means full delivery:

- If the source has a known episode count, create the adapted work at the same episode count unless the user explicitly asks to compress or expand.
- If the source is a long drama and the user asks for overall adaptation, do not stop at "前5集样稿", "pilot sample", or "partial sample".
- A strategy plus first episodes is acceptable only when the user explicitly asks for a proposal, direction test, or sample.
- For a 70+ episode source, deliver a 70+ episode adapted outline and a full script body or clearly ask the user to choose between "full script now" and "direction sample only" before writing.
- If time or context requires staged work, write a complete file-based deliverable plan and begin the full script file; do not present the partial sample as the final adapted result.

For planning only:

1. `可保留的抽象爽点`
2. `必须替换的高风险元素`
3. `三套原创改编方向`
4. `推荐方案`
5. `风险说明`

## Self-Score Rubric

Minimum deliverable score: 90/100.

- Hook extraction and audience value: 15
- Original worldview and causality: 20
- Character motivation and active choices: 15
- Conflict escalation and payoff: 15
- Setup/rule consistency: 10
- Copyright-risk distance: 15
- Dialogue, format, and shootability: 10

If copyright-risk distance is below 12/15, the total score cannot exceed 89.

## Final Delivery Requirements

Always include a concise self-check:

- What was extracted from the source.
- What was replaced or rebuilt.
- Why the new version is not merely a renamed copy.
- Whether the adapted output is complete or only a sample. If it is only a sample, this must match the user's explicit request.
- Final score.
- Remaining risk or recommended legal/licensing note when relevant.
