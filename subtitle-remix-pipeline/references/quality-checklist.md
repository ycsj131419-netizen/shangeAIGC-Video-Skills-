# Quality Checklist

Use this checklist before final delivery.

## Source

- Source files and paths recorded.
- Clean source selected when available.
- Encoding handled correctly.
- Character counts and non-empty line count recorded.
- Episode count verified.
- Trailer/cross-story residue checked.

## Subtitle Calibration

- Missing subtitle line count is 0.
- Every line is mapped to dialogue, OS, narration, screen text, action, reaction, or transition.
- Speaker attribution passes.
- No self-address errors.
- No invented names from source confusion.
- Script is richer than transcript.

## Adaptation

- Abstract hook extracted.
- Protected expression replaced.
- World, identities, industry, resource, antagonist, locations, rules, and ending rebuilt.
- Profit logic is plausible.
- Protagonist skill is visible.
- User's latest direction is followed.
- System/golden-finger trigger and limits are correct when requested.

## Delivery

- Full episode count delivered unless user requested sample/compression.
- Local Markdown file created for long output.
- Feishu/Lark docx imported by default.
- Final score is at least 90.
- Self-check is included in final response.
